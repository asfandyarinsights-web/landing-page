# Being Learner — Tech & Career Academy Landing Page

A responsive, single-page marketing site for **Being Learner**, a fictional tech & career bootcamp brand. The page showcases program offerings, teaching methodology, learner outcomes, and a conversion-focused call-to-action flow.

🔗 **Live Demo:** [asfandyarinsights-web.github.io/landing-page](https://asfandyarinsights-web.github.io/landing-page/)

## ✨ Features

- **Hero section** with headline, dual CTAs, live stats (learners enrolled, placement rate, satisfaction rate), and social proof avatars
- **Programs grid** — 6 course tracks (Full-Stack Engineering, UI/UX Design, Data & AI, Python Automation, Product Strategy, Cloud & DevOps) each with duration, level, and pricing
- **Methodology section** highlighting the "learn by doing" teaching approach
- **4-stage learner journey** — Discover → Learn → Build → Grow
- **Testimonials** from graduates with role and company callouts
- **Newsletter / enrollment CTA** with trust badges (flexible payment, risk-free trial, job placement support)
- **Fully responsive layout** across desktop, tablet, and mobile

## 🛠️ Tech Stack

- **HTML5** — semantic page structure
- **CSS3** — custom styling and responsive layout
- **JavaScript** — interactivity and smooth scrolling/anchors
- **Material Symbols** — icon set used throughout the UI
- **GitHub Pages** — static hosting/deployment

## 🚀 Getting Started

Clone the repo and open it locally — no build step required:

```bash
git clone https://github.com/asfandyarinsights-web/landing-page.git
cd landing-page
```

Then simply open `index.html` in your browser, or serve it locally:

```bash
# Using Python
python -m http.server 5500

# Using Node (http-server)
npx http-server .
```

Visit `http://localhost:5500` (or the port shown) to view the site.

## 📦 Deployment

This project is deployed via **GitHub Pages** directly from the repository. Any push to the main branch (or the configured Pages branch) automatically updates the live site.
